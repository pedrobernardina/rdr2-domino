# Dominó · RDR2

Contador de peças e sugestões de jogada para o dominó modo Draw (1v1) do Red Dead Redemption 2.

**Online:** https://pedrobernardina.github.io/rdr2-domino/

```
pnpm install
pnpm dev     # abre em http://localhost:5173
pnpm test    # testes da lógica (probabilidades, pista, sugestões)
```

O estado da rodada e o idioma (PT/EN, botão no topo) ficam salvos no navegador (localStorage) e voltam ao reabrir a aba.
